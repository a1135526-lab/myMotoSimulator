# 安裝與開啟教學（給第一次玩的人）

這份教學假設你**從來沒寫過程式**。每一步都會告訴你要點哪裡、要打什麼字、成功時畫面長什麼樣子。照順序做，不要跳步驟，大約 15～20 分鐘就能玩到。

> 只想先看看長什麼樣子？這個遊戲是網頁，但目前沒有放在網路上，所以一定要在自己電腦上跑起來。下面就是怎麼做。

## 1. 你需要準備什麼

| 項目     | 說明                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 電腦     | Windows 10 / 11，或 macOS 12 以上。Linux 也可以。手機和平板**不能**安裝，但電腦跑起來後，同一個 Wi-Fi 的手機可以連進來玩（見第 6 步最後）。 |
| 瀏覽器   | **Google Chrome** 或 **Microsoft Edge**（最新版）。Safari、Firefox 也能玩，但 3D 畫面在 Chrome / Edge 最順。                                |
| 網路     | 安裝時要下載約 300 MB 的東西。裝好之後玩遊戲不需要網路。                                                                                    |
| 硬碟空間 | 約 1 GB。                                                                                                                                   |
| 時間     | 第一次約 15～20 分鐘，之後每次開啟只要 10 秒。                                                                                              |

## 2. 安裝 Node.js（遊戲的執行環境）

Node.js 是讓這個遊戲能在你電腦上跑起來的程式。**一定要 20 版以上**。

### 2-1. 先檢查是不是已經裝過

如果你不確定，直接跳到 2-2 安裝即可，重複安裝不會壞掉。

### 2-2. 下載

1. 用瀏覽器打開 **https://nodejs.org/**
2. 首頁有一個大大的綠色按鈕，寫著 **「LTS」**（例如 `22.x.x LTS`）。點它下載。
   - **請選 LTS**，不要選「Current」。LTS 是穩定版。
   - 網站會自動判斷你是 Windows 還是 Mac。

### 2-3. 安裝

**Windows：**

1. 打開剛下載的檔案（檔名像 `node-v22.x.x-x64.msi`，通常在「下載」資料夾）。
2. 一路按 **Next（下一步）**。
3. 看到授權條款時，勾選 **I accept the terms...**，再按 Next。
4. 看到 **「Tools for Native Modules」** 那一頁時，**不要勾**那個框框，直接按 Next。（勾了會多裝一大堆用不到的東西。）
5. 按 **Install**。如果跳出「是否允許此 App 變更你的裝置」，按 **是**。
6. 按 **Finish**。

**macOS：**

1. 打開下載的 `.pkg` 檔。
2. 一路按 **繼續**、**同意**、**安裝**，輸入你的 Mac 開機密碼。
3. 按 **關閉**。

### 2-4. 確認安裝成功

先學會打開「終端機」（下面第 4 步會再用到）：

- **Windows**：按鍵盤左下角的 **Windows 鍵**，輸入 `powershell`，點 **Windows PowerShell**。
- **macOS**：按 **⌘ Command + 空白鍵**，輸入 `terminal`，按 Enter 打開「終端機」。

會出現一個黑色（或白色）的視窗，可以打字。輸入下面這行，然後按 **Enter**：

```
node -v
```

成功的話會看到類似：

```
v22.11.0
```

**數字開頭是 20 以上就對了。**

> ❗ 如果看到「`node` 不是內部或外部命令」或「command not found」：
> 把終端機視窗**整個關掉，重新打開一次**再試。剛裝完 Node.js，舊的視窗不會知道。還是不行就重新開機。

## 3. 下載遊戲

有兩種方法，**選一種就好**：

| 方法                | 適合誰             | 好處                   |
| ------------------- | ------------------ | ---------------------- |
| **A. 下載 ZIP**     | 完全新手           | 最簡單，不用多裝東西   |
| **B. 用 Git clone** | 想之後一鍵更新的人 | 以後更新只要打一行指令 |

### 方法 A：下載 ZIP（推薦新手）

1. 打開遊戲的 GitHub 頁面：**https://github.com/a1135526-lab/myMotoSimulator**
2. 點右上方綠色的 **`<> Code`** 按鈕。
3. 在跳出的選單最下面點 **Download ZIP**。
4. 下載完後，到「下載」資料夾找到 `myMotoSimulator-main.zip`。
5. **解壓縮**：
   - Windows：在檔案上按**右鍵** → **解壓縮全部…** → 按 **解壓縮**。
   - macOS：直接**連點兩下** ZIP 檔。
6. 會得到一個資料夾 `myMotoSimulator-main`。建議把它**搬到桌面**，等一下比較好找。

> ⚠️ 一定要解壓縮！直接在 ZIP 裡面點開是不能玩的。

### 方法 B：用 Git clone

1. 先安裝 Git：
   - Windows：到 **https://git-scm.com/download/win**，下載後一路按 Next 安裝即可（全部用預設值）。
   - macOS：打開終端機輸入 `git --version` 按 Enter，如果沒裝過，系統會跳出視窗問你要不要安裝「命令列開發者工具」，按 **安裝**。
2. 打開終端機（方法同 2-4），輸入下面兩行，**每行打完都按 Enter**：

   ```
   cd Desktop
   git clone https://github.com/a1135526-lab/myMotoSimulator.git
   ```

3. 看到 `Receiving objects: 100%` 和 `done.` 就完成了。桌面上會多一個 `myMotoSimulator` 資料夾。

> 💡 Windows 如果桌面在 OneDrive 裡，`cd Desktop` 可能會說找不到。改打 `cd OneDrive\Desktop`（或 `cd OneDrive\桌面`）。

## 4. 打開終端機並進到遊戲資料夾

接下來所有指令都要在**遊戲資料夾裡**執行。最不容易出錯的方法：

**Windows（最簡單的方法）：**

1. 打開檔案總管，進到遊戲資料夾（`myMotoSimulator` 或 `myMotoSimulator-main`）。
   - 進去後應該看得到 `package.json`、`README.md`、`src` 這些東西。**如果只看到另一個同名資料夾，就再點進去一層。**
2. 在資料夾裡**空白的地方按右鍵** → **在終端機中開啟**。
   - Windows 10 沒有這個選項的話：點上方網址列，把裡面的字整個刪掉，輸入 `powershell`，按 Enter。

**macOS：**

1. 在 Finder 裡找到遊戲資料夾。
2. 在資料夾上按**右鍵**（或 Control + 點一下）→ **服務** → **新增位於檔案夾位置的終端機視窗**。
   - 找不到的話：打開終端機，輸入 `cd `（cd 後面有一個空白），然後**把資料夾直接拖進終端機視窗**，按 Enter。

**確認你在對的地方：** 在終端機輸入：

```
node -e "console.log(require('./package.json').name)"
```

看到 `scooter-dyno-simulator` 就對了。如果看到 `Cannot find module`，代表你不在遊戲資料夾裡，回到上面重做。

## 5. 安裝遊戲需要的套件（只要做一次）

在終端機輸入，按 Enter：

```
npm install
```

- 這會下載遊戲用到的所有套件，大約 **1～5 分鐘**，視網路速度而定。
- 過程中會跑出很多文字，**黃色的 `WARN` 是正常的，不用理它**。
- 如果你是用 ZIP 下載的，可能會看到 `.git can't be found`，**這也是正常的**，不影響遊戲。

**成功的樣子**：最後幾行類似

```
added 612 packages, and audited 613 packages in 1m
```

然後又出現可以打字的提示（`PS C:\...>` 或 `%`）。

> ❗ Windows 如果出現紅字 **「因為這個系統上已停用指令碼執行，所以無法載入 npm.ps1」**：
> 這是 Windows 的安全設定。輸入下面這行按 Enter，問你要不要變更時輸入 `Y` 再按 Enter：
>
> ```
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
>
> 然後重新輸入 `npm install`。（或者改用 `npm.cmd install`，效果一樣。）

## 6. 啟動遊戲

在同一個終端機輸入：

```
npm run dev
```

幾秒後會看到：

```
  VITE v5.4.x  ready in 800 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

1. 打開 Chrome 或 Edge。
2. 在網址列輸入 **`http://localhost:5173`**，按 Enter。
   - Windows 也可以按住 **Ctrl** 再點終端機裡那串網址。
3. 看到機車儀表和馬力機畫面，就成功了！🎉

> ⚠️ **玩的時候不要關掉終端機視窗**。終端機就是遊戲的伺服器，關掉遊戲就停了。縮小它就好。

### 怎麼玩（快速上手）

- 先在畫面上**點一下**，讓鍵盤操作作用到遊戲。
- `↑` 油門、`↓` 煞車、`R` 重置。
- 上方可以切換 **模擬器 / 賽道模式 / 街景模式**。
- 街景模式：`←` `→` 轉向、**停住時按住 `X` 倒車**、`M` 開大地圖導航、`R` 回到道路。
- 聲音預設關閉，右上角「🔇 聲音」可以打開。
- 完整操作說明在 [README.md](../README.md)。

### 用手機玩（選用）

手機要和電腦連**同一個 Wi-Fi**。

1. 在終端機按 **Ctrl + C** 先停止遊戲。
2. 改輸入：

   ```
   npm run dev -- --host
   ```

3. 終端機會多一行 `Network: http://192.168.x.x:5173/`。
4. 在手機瀏覽器輸入**那一串網址**（每台電腦的數字不一樣）。
5. Windows 如果跳出防火牆視窗，勾「私人網路」並按 **允許存取**。

---

## 7. 關掉遊戲、下次再玩

**關掉**：在終端機按 **Ctrl + C**（Mac 也是 Control + C），或直接關掉終端機視窗。

**下次再玩**（不用再 `npm install`）：

1. 照第 4 步，在遊戲資料夾打開終端機。
2. 輸入 `npm run dev`。
3. 瀏覽器打開 `http://localhost:5173`。

---

## 8. 更新到最新版

**用 Git clone 的人**：在遊戲資料夾的終端機輸入

```
git pull
npm install
npm run dev
```

**用 ZIP 的人**：重新做一次第 3 步（下載新的 ZIP），然後第 4、5、6 步。舊資料夾可以刪掉。你在遊戲裡存的改裝設定存在瀏覽器裡，換資料夾不會不見。

## 9. 遇到問題怎麼辦

| 看到的狀況                                             | 怎麼解決                                                                                                                                                |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `node` 或 `npm` 不是內部或外部命令 / command not found | 關掉終端機重開；還不行就重新開機；還不行就重裝 Node.js（第 2 步）。                                                                                     |
| `node -v` 顯示 v18 或更舊                              | 版本太舊。到 nodejs.org 下載 LTS 重新安裝，會直接覆蓋舊版。                                                                                             |
| 已停用指令碼執行，無法載入 `npm.ps1`                   | 見第 5 步的紅框說明。                                                                                                                                   |
| `npm install` 出現 `ENOENT ... package.json`           | 你不在遊戲資料夾裡。回到第 4 步，確認看得到 `package.json`。                                                                                            |
| `npm install` 卡很久或出現 `ETIMEDOUT`、`ECONNRESET`   | 網路問題。換個網路（例如手機熱點）再輸入一次 `npm install`。公司或學校網路有時會擋。                                                                    |
| `npm install` 出現 `EPERM` / `EACCES`（權限不足）      | 把遊戲資料夾搬到桌面或「文件」，不要放在 `C:\Program Files` 或 OneDrive 同步中的資料夾。**不要**用系統管理員或 `sudo` 執行。                            |
| `Port 5173 is in use`                                  | 遊戲已經在另一個終端機開著了。直接用瀏覽器開 `http://localhost:5173`，或把另一個終端機關掉。Vite 也可能自動換成 5174，請看終端機上寫的網址。            |
| 瀏覽器顯示「無法連上這個網站」                         | 終端機是不是被關掉了？重新 `npm run dev`。網址要打 `http://` 不是 `https://`。                                                                          |
| 畫面一片空白                                           | 按 **Ctrl + Shift + R**（Mac：⌘ + Shift + R）強制重新整理。還是空白就換 Chrome 試試。                                                                   |
| 3D 模式出現「此裝置不支援 WebGL」，或 3D 畫面非常卡    | 打開 Chrome 設定 → **系統** → 開啟 **「使用圖形加速功能 (如果可用)」**，重新啟動 Chrome。筆電請插電，並在 Windows「圖形設定」把 Chrome 設成「高效能」。 |
| 按方向鍵車子不會動                                     | 先用滑鼠點一下遊戲畫面（不要點在下拉選單上），再按鍵。                                                                                                  |
| 沒有聲音                                               | 右上角「🔇 聲音」要點開。瀏覽器規定一定要先點過畫面才能放聲音。                                                                                         |
| 街景模式一直顯示載入中                                 | 第一次要建好整個楠梓地圖，較慢的電腦可能要 10～30 秒，請稍等。                                                                                          |

還是解決不了？到 GitHub 頁面的 **Issues** 分頁按 **New issue**，貼上：

1. 你的作業系統（例如 Windows 11）
2. `node -v` 顯示的版本
3. 終端機裡**紅色的錯誤訊息**（整段複製貼上，或截圖）
