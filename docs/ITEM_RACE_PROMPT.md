# 道具賽模式：實作 Prompt

> 這份是給實作者（Claude）的完整規格。照著做，每一節做完都要能通過
> `npm run lint && npm run format:check && npm run typecheck && npm test`，動到 3D／版面再跑 `npm run test:e2e`。
> 專案規則以 [CLAUDE.md](../CLAUDE.md) 為準（分層、300 行上限、固定步長、狀態不可變、繁中文案）。

## 0. 角色與目標

你是這個專案的資深遊戲工程師。請在「揍灰來尬掐」加入**道具賽**模式：賽道繞圈的物理、操控、碰撞不變，另外在賽道上放道具箱，騎過去隨機抽一個道具，用道具加速、干擾或攻擊對手。道具和道具名稱都是**原創**，不要模仿任何既有遊戲的道具名稱、外觀或音效。

設計原則：

1. **騎術仍是主角**：道具是變數，不是決定一切。被打中只是「搖晃減速」，不摔車、不重置（延續「碰撞不重置」）。
2. **落後的人有機會追**：名次越後面越容易抽到強道具。
3. **可重現**：所有隨機數由外部注入 seed；同一個 seed＋同樣的輸入＝同樣的結果（測試與連線同步都靠這點）。
4. **連線公平**：每台裝置只判定「自己的車」有沒有被打中，別人送來的事件一律驗證。

## 1. 玩家的決定（不得更改）

| 項目     | 決定                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 賽道     | 現有 17 條賽道都能開道具賽，**另外新增 2～3 條道具專用賽道**                   |
| 取得道具 | 路上的道具箱，騎過去隨機抽；**依名次加權**（越後面越容易抽到強的）             |
| 道具欄   | 一次 **1 個**，用掉才能拿下一個                                                |
| 被擊中   | **搖晃減速約 1.5 秒**（速度掉到約一半），不摔車、不重置                        |
| 道具類型 | 加速類、路上陷阱、射出去的攻擊、防禦與干擾、**滑板車（讓第一名變慢車 10 秒）** |
| 滑板車   | **打中第一名**；第一名本人抽不到                                               |
| 對手     | 對電腦、好友房間、排位賽                                                       |
| 紀錄     | 計入圈速紀錄，但**另開道具賽榜**，不和一般圈速混在一起                         |
| 排位     | **另開道具排位**，段位與積分和一般排位分開（需要新的 SQL）                     |

## 2. 道具清單（原創）

每個道具都要有：id、中文名、圖示（emoji 即可）、類型、效果數值、電腦車使用時機。數值集中在一個常數表，方便平衡。

| id              | 名稱       | 類型             | 效果                                                                                                                |
| --------------- | ---------- | ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| `nitro`         | 氮氣噴射   | 加速             | 2.0 秒：驅動力 +60%、極速上限 +20 km/h（超過原本極速），排氣管噴火                                                  |
| `triple-boost`  | 三段加速   | 加速             | 3 次短加速（每次 0.8 秒、+40%），每按一次用一段；用完才算用掉                                                       |
| `oil`           | 機油       | 陷阱（往後放）   | 放在自己車後 3 m 的路面，半徑 2.2 m；踩到＝被擊中（打滑搖晃），留在路上 30 秒或被踩一次就消失                       |
| `tacks`         | 圖釘帶     | 陷阱（往後放）   | 橫跨約半個路寬的長條，踩到＝減速 30%（不搖晃）持續 2 秒；存在 30 秒                                                 |
| `cone`          | 三角錐     | 陷阱（往後放）   | 實體障礙，撞到算車對物碰撞（反彈＋掉速，用 `contacts.ts` 的同一套），存在 40 秒                                     |
| `water-balloon` | 水球       | 射擊（往前直射） | 沿賽道中心方向以「發射者速度 + 25 m/s」前進，最多飛 250 m 或 4 秒；碰到車＝被擊中；碰到護欄就破                     |
| `homing`        | 追蹤紙飛機 | 射擊（追前一名） | 鎖定**正前方名次的那一位**，以 55 m/s 沿賽道 s 前進並橫向追蹤；最多 8 秒；護盾可擋                                  |
| `shield`        | 護盾       | 防禦             | 8 秒內擋下一次任何攻擊或陷阱（擋掉即消失），車身外有半透明泡泡                                                      |
| `smoke`         | 煙霧彈     | 干擾             | 在自己身後留下 40 m 長的煙霧帶 6 秒；在煙霧裡的對手畫面變灰霧（同閃大燈的覆蓋層做法，`pointer-events: none`）       |
| `flash`         | 遠光爆閃   | 干擾             | 不限夜間；前方 70 m、40° 光錐內的對手畫面半透明白 1.4 秒（沿用 `roomFlash` 的 `dazzles()`）                         |
| `skateboard`    | 滑板車     | 特殊             | **第一名**（不含自己）10 秒內變成滑板車：外觀換成滑板車模型，驅動力 ×0.35、極速上限 45 km/h；護盾可擋；第一名抽不到 |

被擊中（hit）統一效果：1.5 秒內速度平滑降到進入時的 50%，車身左右搖晃（lean 疊加正弦 ±12°），期間油門效果 ×0.3；之後恢復正常。被擊中期間不會再被同一類效果疊加（有 0.8 秒無敵）。

### 抽道具機率（依名次加權）

以 `place / fieldSize` 正規化成 0（第一）～1（最後），分三段，權重表放在 domain：

| 道具                   | 前段（0～0.33）   | 中段 | 後段（0.67～1） |
| ---------------------- | ----------------- | ---- | --------------- |
| oil / tacks / cone     | 高                | 中   | 低              |
| shield                 | 高                | 中   | 低              |
| water-balloon          | 中                | 中   | 中              |
| nitro / triple-boost   | 低                | 中   | 高              |
| homing / smoke / flash | 低                | 中   | 中              |
| skateboard             | 0（第一名永遠 0） | 低   | 中              |

單人對電腦時只有一位玩家也成立（電腦車一樣照名次抽）。

## 3. 道具箱與道具專用賽道

- **道具箱**：每條賽道在 3～4 個位置各放一排（橫向 3～5 個，視路寬），位置用 `s`（沿賽道距離）＋ `d`（橫向）描述。現有賽道自動產生：避開起跑線前後 150 m 與急彎中段，放在直線或彎出口。被拿走的箱子 **3 秒後重生**（每台裝置各自計時；箱子狀態不同步，只同步「誰抽到什麼」）。
- **3D**：浮在路面上、慢慢旋轉的半透明方塊，上面有「?」；被拿走時縮小消失、重生時放大。
- **道具專用賽道**（新增 2～3 條，放 `src/data/circuits/itemCircuits.ts`）：比一般賽道**寬**（路寬 16～20 m，方便閃道具）、**短**（1.2～1.8 km，道具箱密度高），可以有上下坡；仍須通過 `circuits.test.ts`（彎道半徑 ≥ 40 m、大彎 ≥ 50 m、不同路段不能太近）。卡片上標「🎁 道具賽道」，只在道具賽出現。名稱和外觀原創。

## 4. 分層與檔案配置（遵守 ESLint 分層）

```
src/domain/items/
  itemTypes.ts        道具定義、數值表、ItemId
  itemRoll.ts         依名次加權抽獎（注入 RNG）
  itemBoxes.ts        道具箱配置（由賽道幾何自動產生）、拿取／重生
  itemEffects.ts      作用中效果（boost、hit、shield、skateboard、smoke…）→ 修改騎乘參數
  projectiles.ts      水球／紙飛機的推進與命中判定（在 s/d 座標裡算）
  traps.ts            機油／圖釘／三角錐的放置、碰撞、到期
  itemRace.ts         包住 stepCircuitRace：每步處理拿箱、效果、投射物、陷阱、電腦用道具
  *.test.ts
src/data/circuits/itemCircuits.ts
src/application/race/ItemRaceController.ts（或擴充 CircuitController 的 mode）
src/application/online/room/roomItems.ts      房間內道具事件收發（同 roomHorns / roomFlash 的做法）
src/application/stores/itemStore.ts           HUD 用：手上的道具、作用中效果、被干擾覆蓋層
src/ui/race/items/                            HUD 道具欄、使用按鈕、覆蓋層
src/ui/race/circuit/scene/items/              道具箱、陷阱、投射物、護盾、滑板車模型
```

- `circuitRace.ts` 已接近 300 行：**不要**把道具邏輯塞進去，用 `itemRace.ts` 包一層。需要讓騎乘吃效果時，透過 `RiderContext` 或 `stepRider` 的參數傳入「倍率」（驅動力、極速上限、油門倍率、額外搖晃），domain 仍是純函式。
- 狀態不可變；沒變化時回傳同一個參考。
- 固定步長 `model.timestepS`；所有計時（效果剩餘秒數、箱子重生、陷阱壽命）都用 race clock，不能用 `Date.now()`。

## 5. 操作

- 鍵盤（`circuit` 配置）：**`Z` 使用道具**（新增到 `InputAction`）。同步更新：`KeyboardInputSource` 的 `LAYOUTS`、`TouchInputSource`、`TouchControls`／`OverlayControls`（手機全螢幕要有一顆大的「道具」按鈕，放在右手拇指附近，可被 `controlLayoutStore` 移動）、頁面 `KeyHints`、README 操作表。
- 往後放的陷阱一律放在車後；射擊類一律往前（一次 1 個道具、沒有前後選擇）。
- 三段加速：每按一次 `Z` 用一段，HUD 顯示剩幾段。

## 6. 電腦車

- 電腦車也會拿箱子（它們的行駛線會稍微偏向箱子）並使用道具：
  - 加速類：直線上、前方 200 m 沒有急彎時用。
  - 陷阱：後方 60 m 內有對手時用，否則持有到有人接近。
  - 水球：正前方 80 m 內、橫向差 < 3 m 有對手時用。
  - 紙飛機／滑板車：拿到 1～3 秒內就用。
  - 護盾：被鎖定（有紙飛機追來）時立即用，否則持有。
- 電腦的反應時間與失誤率依 `CIRCUIT_SKILLS` 等級調整（新手偶爾亂用）。

## 7. 連線同步（好友房間、排位）

沿用 `roomTransport` 的 `tapRoomMessages`／`sendToRoom`，新增訊息型別，**全部經 `parseMessage()` 驗證**（id 長度、raceId、數值範圍、道具 id 在白名單內）：

| 訊息         | 內容                                        | 收到後                                                                                                     |
| ------------ | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `itemUse`    | `{ id, raceId, item, s, d, speedMps, seq }` | 依道具在本機重建：陷阱放到 (s,d)、投射物從 (s,d) 以同樣規則推進、干擾類用 `dazzles()` 等判斷自己是否受影響 |
| `itemHit`    | `{ id, raceId, by, item, seq }`             | 自己判定被打中後廣播（讓陷阱／投射物在所有人畫面上消失，也讓結算統計一致）                                 |
| `skateboard` | `{ id, raceId, target }`                    | target 是自己才套用；target 以送出方當下看到的第一名為準                                                   |

- **只有受害者判定自己被打中**；發射者的畫面只是預測。
- 投射物與陷阱用 (s, d) 描述，各裝置同一套規則推進，不需逐幀同步。
- 每人每場的道具使用次數上限（例如 40 次）防止灌訊息；超過的事件丟掉。
- 道具箱的抽獎在自己裝置上做，用 `seed = hash(raceId, playerId, boxIndex, lap)`，讓結果可重現、也方便除錯。

## 8. 紀錄、排行榜、排位

- **本機紀錄**：`recordsStore` 另存道具賽圈速（key 加上 `items:` 前綴或獨立欄位），幽靈車也分開。乾淨圈的定義同一般賽：只有撞牆（`wallHitAtS`）或按 R 不算；被道具打中、用道具加速都照算（道具賽本來就有運氣成分）。
- **全球榜**：新增 `supabase/008_item_race.sql`：
  - `item_lap_times` 表（同 `lap_times` 結構）＋ `submit_item_lap`、`get_item_lap_board` RPC；規則表沿用 `circuits`，但最低圈速用更寬鬆的 100 m/s（考慮氮氣）。道具專用賽道要加進 `circuits`。
  - 道具排位：`ranked_items` 表（或 `ranked` 加 `mode` 欄位）＋ `report_ranked_items`；加減分表與一般排位相同但分開累計。改分數表要 `ranking.ts` 與 SQL 兩邊一起改。
  - 表一律鎖住，只開放 RPC；不放任何 secret。
- **排位配對**：presence 頻道 `mm:items-<group>`，其餘沿用現有 `formMatch()`、20 秒配不到對電腦；賽道從「道具專用賽道＋部分一般賽道」隨機挑。
- **對戰紀錄**：`MatchRecord` 加 `mode: 'items'`，個人資訊頁可篩選；結算畫面多一張「道具統計」卡：用了幾個道具、打中幾次、被打中幾次、最常抽到的道具。

## 9. 介面

- **大廳**：多一張「🎁 道具賽」模式卡（testid `home-items`），進去後流程同賽道繞圈：選賽道（一般賽道＋道具專用賽道）→ 選車 → 調校 → 對手 → 比賽。好友房間的設定多一個「道具賽」開關；排位選單多一個「道具排位」。
- **HUD**：
  - 道具欄：畫面上方中間偏下的一個方框（避開彎道提示），抽到時有約 0.8 秒的「轉輪」動畫再停在結果；顯示道具圖示＋名稱＋按鍵提示。
  - 作用中效果：小圖示列（護盾剩幾秒、滑板車剩幾秒、加速中）。
  - 被鎖定警告：紙飛機追來時邊框閃紅、顯示「⚠ 紙飛機接近」。
  - 被打中：短暫畫面晃動＋「被水球打中！」之類的提示（1 秒，放角落，不擋路面）。
  - 被滑板車：「你被變成滑板車了！10」倒數。
- **手機橫向全螢幕**：道具按鈕夠大、不在 HUD 數字上；覆蓋層全部 `pointer-events: none`。
- **3D**：道具箱、陷阱（機油是深色反光圓片、圖釘帶、三角錐）、投射物（水球、紙飛機）、護盾泡泡、氮氣尾焰、滑板車模型（騎士站姿）。CI 是軟體 WebGL：模型要低面數、共用材質、用 InstancedMesh，不能讓 e2e 逾時。
- **音效**：拿箱、使用、命中、護盾擋下各一個，用 Web Audio 即時合成（同 `hornSounds.ts`），聲音關閉時不播。

## 10. 測試要求

- **domain 單元測試**（覆蓋率 ≥ 80%）：
  - 抽獎權重：同 seed 結果固定；第一名永遠抽不到滑板車；後段抽到加速的機率明顯高於前段（大量抽樣統計）。
  - 被擊中：1.5 秒後速度約為進入時 50%，之後能恢復加速；0.8 秒內不會重複被打。
  - 護盾擋一次就消失；滑板車 10 秒內極速 ≤ 45 km/h、時間到恢復。
  - 水球直線命中、撞護欄消失；紙飛機會追到前一名、被護盾擋下。
  - 陷阱：踩到觸發一次、到期消失；三角錐走車對物碰撞。
  - 道具箱：拿走 3 秒後重生；自動配置避開起跑區與急彎。
  - 電腦車在一場模擬比賽中確實有拿箱和用道具，且全部完賽。
- **application**：`roomItems` 用 `FakeHub` 模擬兩位玩家：A 放機油、B 踩到後雙方的陷阱都消失；A 對第一名 B 用滑板車；不合法的訊息被丟掉。
- **UI**：道具欄顯示與按鈕使用、覆蓋層不擋按鈕（`pointer-events`）。
- **e2e**：從 `home-items` 進入一場道具賽、跑到起跑後按 `Z` 不報錯；手機版沒有水平捲動。
- 道具專用賽道通過 `circuits.test.ts`。
