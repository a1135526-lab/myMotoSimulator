# 開發 Prompt：街景模式 × 新車款 × 擬真建模

> 你是這個專案的資深遊戲／前端工程師。專案使用 React 18、TypeScript strict、Vite、Zustand、Zod 和 Three.js 0.169，分成 domain／data／application／ui 四層，ESLint 有強制分層規則。
> 請在 **不破壞既有功能**（模擬器、直線加速賽、賽道繞圈、儀表、音效）的前提下，完成以下三件事，並遵守最後的品質要求。

---

## 1. 街景模式：開放世界自由騎乘

**目標**：像開放世界動作遊戲那樣，有一座完整的城市地圖，可以隨意在裡面騎車。城市、名稱和素材全部原創，不使用任何現有遊戲的地圖或資產。

### 入口與流程

- 上方分頁新增「街景模式」，和「模擬器」「賽道模式」並列。Three.js 相關程式碼延遲載入。
- 進入後先到設定頁：
  - 選車：沿用車庫的卡片和改裝設定。
  - 時段：白天／黃昏／夜晚。
  - 車流：無／少／多。
  - 騎乘輔助：自動換檔、自動半離合，預設關閉。
- 設定完按「出發」，進入城市。

### 城市（原創「港灣市」）

- 範圍約 1.6 km × 1.6 km，有一段夠長的直線可以騎到極速。
- 風格參考台灣都市：
  - 棋盤式街廓：主幹道 4 線道約 16 m 寬，一般街道約 10 m 寬，並有人行道。
  - 濱海快速道路，沿著城市一側。
  - 公園和廣場。
  - 不同區域：市中心高樓、商業區、住宅區、工業港區、河濱。
- 城市用固定 seed 的決定性程式生成，每次進來都一樣。
  - 生成規則和碰撞屬於 domain 層（純 TS，可測試）。
  - 城市的參數（大小、區域、seed）放在 data 層。

### 騎乘物理

- 縱向：沿用現有的引擎與傳動模擬（`SimModel` / `step`），手動離合、換檔、熄火、自動半離合、自動換檔都要能用。
- 橫向：在世界座標下用壓車轉彎，路徑曲率 κ = g·tanφ / v²，壓車角受抓地力限制；低速時可以直接轉把手。
- 按住煞車可以甩尾，沿用 `drift.ts`。
- 路面會影響抓地力和滾動阻力：
  - 柏油路：抓地力正常。
  - 人行道：抓地力略低。
  - 草地：抓地力低、阻力大。
- 碰撞：
  - 撞到建築、地圖邊界或車流車輛就摔車。
  - 1.5 秒後把車放回最近的道路，車頭朝道路方向。
  - `R` 鍵可以隨時做同樣的事。

### 車流

- AI 汽車依台灣的右側通行，在道路上沿車道行駛。
- 路口轉彎前會減速。
- 密度可以選擇，車種和顏色有變化。

### 鏡頭與 HUD

- 第三人稱追尾和第一人稱（`V` 切換），和賽道模式一致。
- HUD 顯示：
  - 該車的原廠樣式儀表。
  - 小地圖：道路、玩家位置與朝向、車流。
  - 目前所在區域名稱、本次里程、本次極速、時鐘。
  - 摔車或熄火時的提示。

### 操作

| 按鍵      | 功能           |
| --------- | -------------- |
| `↑`       | 油門           |
| `↓`       | 煞車           |
| `←` `→`   | 壓車轉向       |
| `Shift`   | 離合           |
| `E` / `Q` | 升檔／降檔     |
| `Enter`   | 發動           |
| `V`       | 切換視角       |
| `R`       | 回到最近的道路 |

手機上用觸控按鈕操作。

## 2. 新增車款（越多越好）

- 至少新增 **16 台**，涵蓋台灣常見的：
  - 白牌速克達、黃牌／紅牌大羊。
  - 白牌、黃牌、紅牌檔車和重機。
- 品牌包含 SYM、KYMCO、Yamaha、Honda、Suzuki、Kawasaki、KTM、BMW、Ducati、Vespa、Triumph 等。
- 每台車一個資料檔，內容包括：
  - 引擎：排氣量、汽缸數、壓縮比、峰值馬力／扭力和對應轉速、怠速、斷油轉速、轉動慣量。
  - 傳動：CVT（普利珠、變速比、離合器、碗公、齒比），或變速箱（一次減速、各檔齒比、大小齒、起步轉速）。
  - 車身：整備重量、後輪胎規格、風阻面積、滾阻。
  - 儀表樣式（`cluster`）。
  - 資料來源（`provenance`）：查不到原廠數據的數值一律標為「估計值」。
- 所有新車都要通過既有的 Zod schema 和 bikes 測試（峰值重現、各牌照級距的極速與加速合理範圍）。如果重機的極速超出現有範圍，要調整範圍並說明理由。
- 新車在模擬器、車庫、對手、街景模式都能選到。

## 3. 擬真建模：不要像素感

### 渲染

- ACES Filmic 色調映射、sRGB 輸出、抗鋸齒、像素比上限 2。
- PCF 柔和陰影，陰影相機跟著玩家移動。
- 物理天空（`Sky` shader），用 PMREM 產生環境反射。
- 距離霧依時段變化。

### 材質與貼圖

- 全部改用 `MeshStandardMaterial`，設定 roughness 和 metalness。
- 貼圖用程式產生，至少 1024 px，開啟 mipmap 和各向異性過濾，**不使用 NearestFilter**：
  - 瀝青：細骨材、補丁、輪跡。
  - 人行道磚。
  - 建築立面：窗格、樓層線、多種外牆材質。
  - 草地。

### 道路

- 車道虛線、路緣實線、雙黃線、斑馬線、停止線。
- 路緣石和人行道有高低差。

### 街道物件

- 路燈：夜間發光。
- 紅綠燈、行道樹、公車亭、護欄、店面招牌。

### 建築

- 高度和外觀依區域變化，頂樓有設備（水塔、冷氣）。
- 夜間窗戶隨機亮燈。

### 機車模型

- 提升細節：輪框、碟煞、排氣管、頭燈／尾燈、整流罩。
- 所有模式共用同一套模型。

### 效能

- 大量物件使用 `InstancedMesh` 或合併幾何。
- 目標桌機 60 fps。
