## 賽道模式（3D）

上方切到「賽道模式」，第一步先選 **直線加速賽** 或 **賽道繞圈**，再依序選賽道、機車、配備、對手後進入比賽。

### 直線加速賽

用騎士第一人稱視角跟 AI 對手比直線加速：

1. **賽道**：每條賽道都會影響物理和 3D 畫面。

   | 賽道         | 距離       | 條件                                      |
   | ------------ | ---------- | ----------------------------------------- |
   | 中央賽車場   | 402 m      | 白天、看台                                |
   | 海線夜間公路 | 201 m      | 夜間、海景、抓地力 0.95 G                 |
   | 山區爬坡     | 1000 m     | 黃昏、上坡 4%、海拔 1,200 m（空氣較稀薄） |
   | 雨天濕地     | 402 m      | 下雨、抓地力 0.6 G（起步容易打滑）        |
   | 自訂賽道     | 50～3000 m | 白天                                      |

   起跑燈可選業餘（黃燈逐一亮）或職業（黃燈齊亮，0.4 秒後亮綠燈）。

2. **機車**：39 台車用卡片呈現，顯示排氣量、汽缸數、馬力、車重、馬力重量比，以及「在這條賽道的原廠預估 ET」。
3. **配備**：一鍵套用原廠、輕改、重改，或展開詳細調校。右側即時顯示峰值馬力、預估 ET、終點速度和原廠的差距。車庫和模擬器共用同一份設定。
   - 打檔車可選 **離合器模式**：「自動半離合」（只管換檔，起步自動半離合、停車不熄火；按住 `↓`＋`↑` 可原地拉轉速，放開 `↓` 就起步），或「全手動離合」（預設；`Shift` 自己控制半離合，放太快會熄火）。
4. **對手**：同樣用卡片選車，再選改裝等級、騎士技術（新手 / 一般 / 職業）和體重。上方會預估雙方的 ET 和勝負。
   - 技術會影響起跑反應、放離合的手法，以及換檔點（早換 / 拉到斷油 / 最佳換檔點）。
   - 起跑反應和真人相同：新手約 0.27 秒、一般約 0.21 秒、職業約 0.16 秒（每場隨機小幅浮動），不會低於人體極限。
   - 速克達對手在倒數時會「壓煞車拉轉」（brake stand）。

比賽中可按「返回車庫」，或在結果畫面按「換車 / 改裝」回到配備步驟。

- **操作**：`Space` 開始倒數，比完按 `Space` 再比一場；`R` 回到起跑線。其餘按鍵和模擬器相同。
- **規則**：第一顆黃燈亮起前車子會自動幫你煞住；之後要自己按住車（`↓` 煞車或拉離合）。搶跑判定看的是「你的手」：
  - 綠燈前就放煞車／放離合催油，算搶跑。
  - 綠燈後 **0.1 秒內** 就起步也算搶跑。人看到燈號再動手不可能快過 0.1 秒（田徑起跑也用同一個標準），所以這種起步一定是猜燈。
  - 搶跑直接判負，結果畫面會說明原因。成績有：起步反應（綠燈到你的手起步）、RT（綠燈到車輪離開起跑光束）、ET（光束到終點）、總時間（RT + ET，決定勝負），以及終點速度。
- 3D 賽車模式另外打包，只在切換進來時才下載；不支援 WebGL 的裝置會顯示提示，但仍可以照常比賽。

## 賽道繞圈（3D）

在「賽道模式」的第一步選「賽道繞圈」，可以和 1～3 個 AI 對手在原創賽道上跑多圈。

| 賽道           | 全長    | 特色                             |
| -------------- | ------- | -------------------------------- |
| 練習場         | 1.27 km | 有髮夾彎（R 19 m），適合熟悉操作 |
| 山城技術賽道   | 2.17 km | 連續彎、黃昏、海拔 600 m         |
| 南灣國際賽車場 | 3.45 km | 長直線、大半徑高速彎、海景       |

**操作（賽道模式的鍵盤配置）**

| 按鍵              | 功能                                 |
| ----------------- | ------------------------------------ |
| `↑` / `W`         | 油門                                 |
| `↓` / `S`         | 煞車                                 |
| `←` `→` / `A` `D` | 壓車轉向                             |
| `↓` + `←`/`→`     | 煞車甩尾（入彎太快時多轉一點）       |
| `E` / `Q`         | 升檔／降檔（關閉自動換檔時）         |
| `Shift`           | 離合器（關閉自動換檔時）             |
| `V`               | 切換第一人稱／第三人稱               |
| `R`               | 回到賽道中線                         |
| `Space`           | 開始亮燈（5 顆紅燈全亮後熄滅即起跑） |

- **起跑**：按 `Space` 後，第一顆紅燈亮之前車子會自動煞住。之後要自己按住 `↓`（可同時催油拉轉速），紅燈熄滅後放開起跑。
  - 紅燈熄滅前起步，或熄滅後 0.1 秒內就起步，算偷跑，要在原地罰停到熄燈後 3 秒。
  - 起步後畫面會顯示你的反應時間。AI 對手的反應約 0.16～0.27 秒，跟真人一樣。

- 所有輔助（轉向、煞車、自動換檔、自動半離合）**預設都關閉**，需要時在設定頁打開。
- **轉向輔助**（預設關）：車子會自動壓車跟著彎道走，左右鍵用來微調走線。關掉後左右鍵直接控制壓車角。
- **煞車輔助**（預設關）：入彎太快時自動收油、煞車，按住油門也能跑完一圈，速度約等於「一般」對手；想贏「職業」對手就關掉，自己晚煞車。
- **煞車甩尾**：入彎時按住煞車再按方向鍵，後輪會滑出去，比單靠壓車多約 0.55 G 的轉向力，但速度掉得也快。開著轉向輔助時，甩尾只補「壓車壓到底還不夠」的那部分，不會把你甩進內側草地。
- **自動換檔**（預設關）：打檔車會自動換檔，起步時自動半離合。關掉後依「配備」頁的離合器模式：自動半離合（自己換檔）或全手動離合。
- **甩尾可以一直維持**：方向鍵決定往哪邊滑，之後只要一直按住煞車就會持續滑行，方向鍵放開也一樣。滑行時只有後輪在煞，速度掉得慢，補一點油門就能撐住；往反方向打可以把車拉直。
- 入彎太快會跑出柏油路：碎石區和草地的抓地力低、阻力大，撞到護欄會摔車，2.5 秒後回到賽道。在草地上按方向鍵可以把車拉回來，多出約 0.6 G 的轉向力（腳點地、甩後輪的感覺）。
- 預設是**第一人稱**：畫面會隨壓車角傾斜，像車載鏡頭；按 `V` 切到第三人稱，鏡頭在車後方跟隨。賽道繞圈和街景模式都一樣。
- HUD 顯示名次、圈數、本圈／上圈／最快圈、小地圖和壓車角，時速、檔位和轉速則顯示在 **原廠樣式的儀表** 上（見下方）。

## 街景模式（3D 開放世界・高雄市楠梓區）

上方切到「街景模式」，選好車、時段（白天／黃昏／夜晚）和車流（無／少／多），按「出發」，就從 **楠梓火車站前的建楠路** 出發，在真實的楠梓街道上自由騎乘。

- **真實地圖**：路網、路名、單行道、河川、公園、學校和地標，都來自 **OpenStreetMap**。
  - 範圍約 5.1 × 4.4 km：楠梓舊市區、右昌、後勁、德民路、高楠公路、加昌路、楠梓科技園區、後勁溪與楠梓溪。
  - 2,583 個路口、約 300 km 道路、236 個有號誌路口、49 個里、595 個地標。
  - 不包含國道和地下道。
- **建築**：OSM 上有外框的約 1,000 棟用真實外形和樓層。其他沿街面以固定 seed 補上，總共約 17,000 棟。
  - 巷弄：3～5 樓透天連棟。
  - 主要道路：4～11 樓店面大樓，有雨遮和直立招牌。
  - 商業區有高樓，工業區是低矮廠房。
  - 公園、學校、河川和道路上不會蓋房子。
- **大地圖與導航**：按 `M`，或點右上角的小地圖。
  - 打開大地圖時遊戲會暫停。可以拖曳平移、滾輪或 `＋`／`－` 縮放、「我的位置」回到自己。
  - 地圖上有路名、地標圖示、指北針、比例尺和圖例。
  - 搜尋地標或路名（例如「楠梓車站」「右昌國民中學」「德民路」），或依類別列出最近的車站、捷運站、學校、醫院、公園、便利商店、加油站等。在地圖上點一下也能設定目的地。
  - 路線用 **A\*** 在真實路網上規劃，會遵守單行道，並稍微偏好大路。
  - 導航卡片顯示下一個動作（直行、靠左／右、左／右轉、迴轉、抵達）、距離、路名、剩餘距離和預估時間。
  - 路面上會畫出導航路線，目的地有光柱。
  - 偏離路線超過 25 m 會自動重新規劃，距離目的地 20 m 以內算抵達。
- **小地圖**：預設車頭朝上，點 `N` 可以改成北方朝上。顯示路網、車流和導航路線，下方是目前的路名；左上角顯示所在的里。
- **車流**：AI 汽車行駛在主要道路與一般道路上，靠右、遵守單行道。
  - 在路口依角度選擇直行或轉彎，轉彎前會減速。
  - 會跟車，也會停下來讓你。
  - 遠離你的車會移到你附近，讓周圍一直有車。
- **倒車**：停住（或幾乎停住）且沒催油時，按住 `X` 會用腳往後推，最快約 4 km/h，儀表顯示 `R`。放開或按煞車就停下。倒車時轉向會反過來，跟真的牽車一樣。手機版有「倒車」按鈕。
- **騎乘**：引擎、變速箱、壓車、甩尾與賽道模式相同。撞到建築、騎進河裡或超出地圖邊界會摔車，1.5 秒後放回最近道路的右側車道；按 `R` 也一樣。
- **畫面**：
  - 物理天空、環境反射、ACES 色調映射、柔和陰影。
  - 道路沿真實折線鋪設，有標線、號誌路口的斑馬線和停止線、真實位置的紅綠燈。
  - 大路有人行道和路緣石，還有路燈和行道樹。
  - 車站、學校、醫院上方有名稱看板。
  - 所有幾何依 300 m 區塊合併並做視錐剔除。

操作：`↑` 油門、`↓` 煞車、`←` `→` 壓車、`↓` + `←`/`→` 甩尾、`X`（停住時按住）倒車、`E`/`Q` 換檔、`Shift` 離合、`Enter` 發動、`V` 視角、`M` 大地圖／導航、`R` 回到道路。

## 大廳與個人資訊

打開遊戲會先進到**大廳**：中間用卡片選模式（排位賽、好友對戰、賽道繞圈、直線加速、街景、馬力機），每個模式頁面左上角的「← 大廳」隨時可以回來。

- 大廳和卡片的背景是遊戲本身的 3D 畫面截圖（`scripts/art/capture-art.mjs` 產生）。
- 大廳、個人資訊和好友房間會播放**背景音樂**：用 Web Audio 即時合成的原創合成器樂曲，沒有使用任何音檔或有版權的歌曲。右上角「🎵 音樂」可以開關（設定會記住）；瀏覽器規定要先點一下畫面才會出聲。進入比賽後音樂會淡出，讓位給引擎聲。

左上角的頭像點進**個人資訊**，裡面有所有對戰數據：

- 總場次、勝場、勝率、前三名次數、完賽率、未完賽／搶跑次數、平均名次、目前連勝、最長連勝、累計比賽時間。
- 各模式戰績（排位賽、好友對戰、賽道對 AI、直線加速對 AI）。
- 常用車款：每台車的場次、勝場、勝率。
- 賽道紀錄：每條賽道的場次、勝場、最佳成績。
- 好友交手：和每位朋友同場幾次、贏幾次、輸幾次。
- 最近 30 場對戰的詳細紀錄（名次、時間、車款、對手）。

對戰紀錄存在裝置上；用 Google 登入後會**自動同步到帳號**，換手機或電腦也看得到（登入前打的場次也會補傳）。

## 好友

用 Google 登入並取暱稱後，大廳左上角的「👥 好友」可以：

- **加好友**：輸入對方的暱稱送出邀請，對方接受後就成為好友（如果對方也剛好加過你，會直接成為好友）。也可以在好友房間裡，按其他玩家旁邊的「＋好友」。
- 看誰在線上（🟢），**邀請比賽**：自動開一個房間並把房號傳給對方，對方畫面會跳出「加入」按鈕。在房間裡也可以從「邀請好友」直接邀請。
- **查看資訊**：好友的場次、勝率、常用車款和最近的對戰。
- 接受／拒絕好友邀請、移除好友、取消送出的邀請。

## 好友對戰（線上）

賽道模式第一步選「👥 好友對戰」，和朋友在同一條賽道即時比賽，最多 4 人，**不用登入**。

1. 輸入名字 → 「建立房間」，畫面會顯示 5 碼**房號**（按「📋 複製邀請」可以直接傳給朋友）。
2. 朋友選「好友對戰」→ 輸入房號 → 「加入」。
3. **房主**選賽道和圈數，**每個人**選自己的車（改裝沿用車庫）。
4. 房主按「🏁 開始比賽」，所有人看到同一組起跑燈、同時熄燈。
5. 比賽中看得到其他人的車和即時名次。
6. **第一名過終點後，其他人只剩 15 秒**：畫面中央會倒數，倒數結束還沒過線就判定「未完賽」。判定看的是每個人回報的完賽時間（比第一名晚超過 15 秒就不算），所以所有人看到的結果一致。
7. 過線後先跳出 **VICTORY**（或你的名次），再進**結算畫面**：名次、總時間、最快圈、完整成績表，以及**對手清單**——可以「查看」對方的排位段位（是好友的話還能看完整戰績），或直接「＋好友」。
8. 結算畫面選「再來一場」或「離開房間」：房主按「再來一場」就直接開下一場（會看到幾個人想再來）；其他人按「再來一場」會通知房主，等房主開始。

- 每個人的物理都在自己的裝置上計算，位置每秒傳 10 次給其他人，畫面上會晚約 0.15 秒（讓動作平順）。
- 車和車之間**不會碰撞**（跟幽靈車一樣可以穿過）。
- 房主離開時，由最早加入的人接任；超過 5 秒沒收到某人的位置，就把他從畫面上移除。
- 比賽中加入的人，會等下一場開始。
- 在房間裡跑出的乾淨圈，一樣會記到本機和全球排行榜（有登入的話）。

## 排位賽（線上配對）

大廳選「🏆 排位賽」，要先用 Google 登入並取暱稱。分兩組，各自有段位：

| 組別     | 大家都騎                   |
| -------- | -------------------------- |
| 速克達組 | SYM JET SL 125（原廠）     |
| 打檔車組 | Kawasaki Ninja 400（原廠） |

- 按「開始配對」會找同一組、**正在排隊的線上玩家**，最多 4 人。一開始只配積分相差 120 分以內的人，等越久範圍越大；等 8 秒後有 2 人以上就開賽。
- **20 秒內沒配到人就改跟電腦比**（3 台電腦）。電腦的實力跟著你的段位提高，但最低和最高段位的差距不大，青銅也不會被電腦屠殺、大師也不會輕鬆贏。
- 賽道繞圈 2 圈，每場隨機一條賽道；**禁止轉向輔助和煞車輔助**，可以用自動換檔／自動離合。排位選單的「操作設定」可以切換自動換檔、自動半離合、傾斜轉向（陀螺儀）和甩動換檔，比賽中上方的按鈕也能切換。
- 第一名過線後其他人只剩 15 秒（同好友對戰，跟電腦比也一樣，畫面上會倒數）。
- 積分：4 人 第 1 名 +30、第 2 名 +12、第 3 名 −6、第 4 名 −18；3 人 +28 / +4 / −16；2 人 贏 +24、輸 −18。跟電腦比的加減分減半，積分不會低於 0。
- 段位：青銅 0 → 白銀 100 → 黃金 250 → 白金 450 → 鑽石 700 → 大師 1000 分。
- 積分由伺服器依你回報的名次計算，每場只能回報一次、30 秒內最多一場。名次是由各自的裝置回報的，目前沒有防作弊。
- 過線後一樣先跳出 VICTORY／名次，結算畫面多了這場的加減分和新段位；可以查看對手、加好友，再選「再來一場」（重新配對）或「離開」。
- 每組各有一個排位排行榜；排位賽的場次也會出現在對戰紀錄裡。

## 任務、幽靈車、排行榜

- **街景任務**：街景模式按「🏁 任務」，從 9 個任務中選一個（送公文到楠梓區公所、急送藥品到健仁醫院……一路到最遠的右昌國中）。
  - 每次都從**楠梓火車站**出發，導航自動設好，計時器顯示在導航卡下方。
  - 限時 = 路線長度 ÷ 30 km/h + 15 秒。限時的 70% 內抵達 ★★★、85% 內 ★★、限時內 ★，超時也算完成但沒有星。
  - 結束後顯示用時、摔車次數、本機排名，可以「再挑戰」。按導航卡的「結束任務」可以中途放棄。
- **幽靈車**：賽道繞圈時，會有一台半透明的藍色機車，跑你在這條賽道**最快的一圈**。
  - 跑出更快的一圈，幽靈車立刻換成新紀錄，下一圈就跟新紀錄比。
  - 按「👻」可以隱藏。
- **本機排行榜**：每條賽道保留前 10 名圈速，每個任務保留前 5 名。
  - 賽道結果畫面和選賽道的卡片上都看得到；開著轉向或煞車輔助的圈會標「輔助」。
  - 只有**乾淨的一圈**才算：中途摔車或按 `R` 重置的圈不列入紀錄，也不會變成幽靈車。
  - 紀錄存在這台裝置的瀏覽器裡（清除網站資料就會不見）。
- **全球排行榜**：右上角「🔑 Google 登入」並取一個暱稱（2～16 字）後，乾淨的賽道圈速、直線加速 ET（固定賽道）、任務用時會**自動上傳**。
  - 按「🏆 排行榜」看所有玩家的成績：賽道分「無輔助／有輔助」兩個榜，直線加速每條賽道一個榜，每個任務一個榜。
  - 賽道榜上可以按「👻 挑戰」，下載那位玩家的最佳圈當幽靈車。
  - 伺服器會檢查成績是否合理（物理極限、幽靈車路線、上傳頻率），每個榜只保留每個人的最佳成績。
  - 不登入也能玩完整遊戲，什麼都不會上傳。見 [隱私權政策](public/privacy.html)；設定方式見 [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)。

## 引擎聲

右上角的「聲音」按鈕可以開關（預設關閉，因為瀏覽器規定要先點擊才能播放聲音；設定會記住）。

- 聲音全部用 Web Audio API 即時合成，不用任何音檔。
- 音高 = 排氣脈衝頻率 = 轉速 ÷ 60 × 汽缸數 ÷ 2，所以單缸、雙缸、三缸、四缸的聲音都不一樣。
- 開油門時聲音更大、更亮、更粗糙；收油時悶下來；碰到斷油會斷斷續續；熄火就沒聲音。
- 風切聲隨車速變大。
- 比賽時也聽得到對手的引擎聲，從右邊傳來，距離越遠越小聲。

## 操作

| 按鍵      | 功能                                                |
| --------- | --------------------------------------------------- |
| `↑` / `W` | 油門（按住漸開，約 0.35 秒全開）                    |
| `↓` / `S` | 煞車                                                |
| `R`       | 重置回靜止                                          |
| `Space`   | 開始 / 停止 0–60、0–100 km/h、0–100 m、0–400 m 計時 |

打檔車另外：

| 按鍵          | 功能                                                      |
| ------------- | --------------------------------------------------------- |
| `Shift` / `C` | 離合器（按住＝拉離合；放開後約 0.6 秒漸進接合，可半離合） |
| `→` / `E`     | 升檔（N → 1 → 2 … → 6）                                   |
| `←` / `Q`     | 降檔                                                      |
| `Enter`       | 發動（需在空檔，或拉著離合）                              |

起步：按住 `Shift` → `→` 入 1 檔 → 按住 `↑` 催油 → 放開 `Shift`。在怠速直接放離合、或低轉速硬拖都會熄火。

手機上使用畫面下方的按鈕（打檔車多出「離合 / 降檔 / 升檔 / 發動」）。

## 手機玩法

- **橫向全螢幕**：在直線加速、賽道繞圈、街景模式把手機**橫過來**，畫面會自動變成全螢幕，按鈕半透明疊在畫面上：
  - 左手拇指：`◀` `▶` 轉向（直線加速是煞車），打檔車多一顆離合，街景多一顆倒車。
  - 右手拇指：油門、煞車，打檔車多出升檔、降檔、發動。
  - 可以多指同時操作，例如按住離合再按升檔。
  - **自訂按鈕位置**：按左上角 `✥` 進入編輯模式，把按鈕拖到想要的位置，也可以調整整體大小；按「重設」回到預設，按「完成」結束。位置會記在這台手機上。直線加速，和「賽道繞圈＋街景」，各有一套配置。
- **傾斜轉向（陀螺儀）**：在賽道繞圈和街景模式按「📱 傾斜轉向」，就能像握方向盤一樣**轉動手機**來轉彎。
  - 開啟時手機的角度就是「直走」；轉約 25° 是全轉，有一點死區，手抖不會讓車子晃。
  - 轉向按鈕還是可以用，按下按鈕時以按鈕為主。
  - iPhone 會詢問是否允許使用「動作與方向」，要按「允許」。每次開啟遊戲都要重新按一次。
  - 需要 https 網址（例如上面的遊戲網址）。用 `npm run dev -- --host` 的區網網址時，iPhone 讀不到感測器。
- **甩動換檔（打檔車）**：按「↕ 甩動換檔」後，橫拿手機**往前甩一下（上緣往外）升檔**，**往自己的方向甩一下退檔**。
  - 要在約 0.2 秒內前後傾斜超過 14° 才算，慢慢調整握姿不會換檔；甩完回到原位也不會被當成反向換檔。
  - 跟傾斜轉向可以同時開：轉向看的是「像方向盤一樣左右轉」，換檔看的是「前後甩」。
  - 只在打檔車、而且沒開自動換檔時出現。Android 換檔時會震一下；iPhone 的 Safari 不支援網頁震動。
- **加入主畫面（PWA）**：
  - iPhone：用 Safari 打開遊戲網址 → 下方「分享」按鈕 → 「加入主畫面」。從主畫面開啟就沒有網址列，是最完整的全螢幕。（iPhone 的 Safari 不允許網頁自己進入全螢幕，所以要用這個方法。）
  - Android：Chrome 選單 →「安裝應用程式」或「加到主畫面」。也可以在 3D 模式按 `⛶` 直接全螢幕並鎖定橫向。
  - 第一次開啟後會把整個遊戲（包括楠梓地圖）存在手機裡，**沒有網路也能玩**。
  - 有新版本時，畫面下方會出現「有新版本可以更新」，按「更新」才會重新載入，不會在比賽中突然中斷。

## 資料可信度

每個規格區塊都有 `provenance`（來源類型、是否查證、來源連結）。未查證的數值在畫面上會標示 **「估計值」**。目前三台車的馬力、扭力、車重、輪胎來自三陽官網；CVT 內部參數（變速比、換檔轉速、離合器）原廠未公開，為工程估計。有實測資料時，請更新資料檔並附上來源。
